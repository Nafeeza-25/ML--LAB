# Experiment 10 – Mini Project

## AI-Generated Image Detection Using CNN with Grad-CAM

This mini project uses a Convolutional Neural Network (CNN) to classify images as REAL or AI-GENERATED.

Grad-CAM is used to provide visual explanations of the model's predictions.

### Technologies Used

- Python
- TensorFlow / Keras
- CNN
- Grad-CAM
- OpenCV
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### Dataset

CIFAKE – Real and AI-Generated Synthetic Images.

### Project Features

- Image preprocessing
- CNN model training
- Binary image classification
- Model evaluation
- Confusion matrix
- Classification report
- ROC curve and ROC-AUC
- Grad-CAM visualization
- REAL image prediction
- AI-GENERATED image prediction

### Files

- `AI_Generated_Image_Detection_CNN_GradCAM.ipynb` – Complete project implementation
- `AI_Image_Detection_CNN.keras` – Trained CNN model
